# 幻盘 · 定价

> 一句话：软件免费开源，U 盘收个成本价，真正能持续赚钱的是后面的模型额度和落地服务。

## 分几层

| 层 | 收不收费 | 说明 |
|---|---|---|
| 软件（本仓库代码） | **免费** | MIT 开源，谁都能拿源码自己搭，不用花一分钱 |
| U 盘实体（预灌装） | **收，盖成本** | 硬件 + 灌装 + 一张激活码，定价只盖住这几样，不指望它赚，图个「拿在手里是个东西」 |
| 模型额度（中转/聚合） | **按量** | 用户要跑 AI 就得烧 token，这块是持续性收入，见下 |
| 人设模板包 | 增值 | 一套调好的人设/技能/语气，开箱更像「你」 |
| 企业落地 / 定制 | 面议 | 私有化、批量装机、内网版、白标 |

## 为什么 U 盘只盖成本

- U 盘本身不是卖点，是**入口**。客户为「拿在手里、插上就能用、有人兜底」付费，
  不为几块钱的硬件付费。
- 定价逻辑：`U 盘硬件成本 + 灌装人工 + 激活码` ≈ 成本价，别加太多毛利。
  加多了显得在收「智商税」，加少了覆盖不了成本。
- 真正的利润在后面：客户用起来 → 烧 token → 走你的中转 → 按量持续收。

## 模型额度（持续性收入的核心）

客户插上 U 盘能跑，但 AI 要烧 token。给两条路：

1. **自带 Key**：客户自己有模型 API，自己烧，你不管。
   （软件免费，这条路你不赚额度钱，但赚了他的使用习惯和后续落地。）
2. **用你的中转/聚合**（推荐）：客户没 Key 或嫌烦，用你提供的中转入口，
   一个 Key 调多家模型，按量计费，人民币结算，免折腾。
   —— 这块对标虾盘的「虾盘云」，是真正的现金流。

**定价锚点**：贴着你进货的价格出，别贪差价。中转这块赚的是「便利 + 省心」，
不是「我比你多收 3 倍」。差价留太厚客户一算账就跑了，贴近平价 + 提供便利，
客户才留得住。

> 合规提示：走中转/聚合，确认上游协议允许转售（resell）。走官方合作进货比
> 自建聚合干净，风险低，优先官方渠道。

## 人设模板包（增值）

一套调好的人设/技能/语气，客户买 U 盘时可选加购，开箱更像一个「成品」而非空壳。
对标虾盘的「企业定制」思路，但做成轻量 SKU。

## 企业落地 / 定制（大单）

对标虾盘的企业服务定价思路（诊断 → 方案 → POC → 陪跑 → 定制）：
- 需求诊断：免费
- 方案设计：按项目收
- 快速 POC：两周内出能演示的原型
- 落地陪跑：从方案到上线全程跟
- 企业定制：私有化部署、批量装机、内网版、白标，面议

## 一句话总结

> **U 盘是钩子，软件是信任，token 是现金流，落地是大单。**
> 别指望 U 盘赚钱，指望「他插上就离不开，离不开就一直烧你的额度」。
