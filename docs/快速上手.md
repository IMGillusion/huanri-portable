# 幻盘 · 快速上手

> 把常驻 AI 分身装进 U 盘：插上任意电脑，人设、记忆、通道都跟着走，双击就能跟你说话。

## 它是啥

普通 AI 是「你问它答」，用完就没。幻盘是一个**常驻**的 AI 分身——它一直在线，
接在你常用的聊天工具上（QQ / Telegram / Discord / 微信…），有自己的性格和记忆，
拔 U 盘换台电脑它还是它。

技术底座是开源的 [Hermes Agent](https://github.com/NousResearch/hermes-agent)，
幻盘做的是「把它装进 U 盘、配置跟人走、开箱即用」这一层。

## 三步开始

### 第 1 步 · 把 portable/ 拷进 U 盘

```
U盘/
└── portable/
    ├── setup.bat        ← Windows 双击这个
    ├── setup.sh         ← macOS/Linux 跑这个
    ├── start.bat
    ├── start.sh
    ├── data/            ← 你的分身全部家当都住这，跟盘走
    └── venv/            ← setup 时自动生成，别动
```

### 第 2 步 · 装运行时（一次）

- **Windows**：双击 `setup.bat`
- **macOS / Linux**：终端里 `cd` 进 portable 目录，跑 `./setup.sh`

setup 会自动建虚拟环境、装 Hermes、补依赖。国内默认走清华源，慢的话设
`HERMES_PIP_INDEX` 换个源。装完看到「✓ setup 完成」就行。

### 第 3 步 · 起分身（每次）

- **Windows**：双击 `start.bat`
- **macOS / Linux**：`./start.sh`

首次起会自动进配置向导：
1. 填你的模型 Key（OpenAI / Anthropic / 任意 OpenAI 兼容接口都行）
2. 选一个通道，填它的 token
3. 完事，你的分身就上线了

## 后台常驻（关掉终端也在线）

```
./start.sh -d          # 后台起，日志在 portable/data/gateway.log
tail -f portable/data/gateway.log   # 看它说啥
pkill -f 'HERMES_HOME=.*data/.huanri'   # 停掉
```

Windows 想后台常驻，建个计划任务开机自启 `start.bat`，或用任务计划程序指向
`venv\Scripts\hermes.exe gateway`，环境变量 `HERMES_HOME` 设成你的 data 目录。

## 换电脑 / 换人

整个 `data/.huanri` 就是分身的全部——配置、记忆、会话、技能、人设。
- 想让新电脑上还是这个分身 → U 盘插上去，跑 `start`
- 想给另一个人一个全新分身 → 把 `data/` 清空，重新 setup，重填 Key
- 拔盘不留痕：主机上不会残留任何分身数据

## 让它「像你」

跑 `hermes` 进配置时，或手编辑 `data/.huanri/persona.md`，写清楚：
- 你希望它怎么称呼你
- 说话风格（短/长、要不要感叹号、用什么语气）
- 边界（什么不聊、什么不碰）

不写就是默认助手；写得越具体，它越像你。

## 常见问题

**Q：一定要 U 盘吗？**
不必。`portable/` 拷到任何目录都能跑，U 盘只是「随身」的载体。

**Q：模型 Key 要花多少钱？**
看你用的哪家、跑多少。中转/聚合见 `docs/定价.md`。

**Q：Windows 提示脚本被拦截？**
右键 setup.bat → 属性 → 点「解除锁定」，或直接复制到其他盘再跑。

**Q：装的时候卡在某一步？**
先看有没有网。没网就先解决网络，或设 `HERMES_PIP_INDEX` 指到能通的镜像源。
